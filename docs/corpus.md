# Corpus

## Primary Dataset

The retrieval corpus for the Fintech Research Agent is the
`embedding-benchmark/FinQA` dataset on Hugging Face.

- Dataset: `embedding-benchmark/FinQA`
- Source: https://huggingface.co/datasets/embedding-benchmark/FinQA
- Accessed: TBD (date of first download)
- Type: retrieval-formatted version of the original FinQA dataset

FinQA is a financial question-answering dataset for numerical reasoning
over financial reports, where answers depend on both text and tables.
The original FinQA release is described as containing roughly 2.8k
financial reports and 8k question-answer pairs. Those figures describe
the original dataset, not necessarily this repackaged version. The
counts for the data actually used in this project are recorded below.

## Data Handling

FinQA is an external data dependency and is not committed to this
repository.

- The Hugging Face `datasets` library downloads and caches the raw data
  locally. The cache is not committed.
- Processed files generated by the pipeline are written to `data/`,
  which is git-ignored.
- The dataset is small (about 1.72 MB), so the plan is to use the full
  dataset. A subsample is only introduced if the inspection shows a
  reason for one.

## Splits and Reproducibility

- The queries are split into train, validation and test sets by query,
  so no query appears in more than one split. The splits are used for
  fine-tuning and evaluating the reranker.

## Future Corpus Expansion

SEC, RBI, SEBI and BIS documents are reserved for a possible later
expansion (Batch 2). They are not part of the initial FinQA experiment.

A larger corpus would test whether retrieval and the agent hold up on
real-world financial, regulatory and policy documents beyond the
benchmark. It would also make retrieval harder, since a small corpus
tends to make retrieval look easier than it will be at scale.
